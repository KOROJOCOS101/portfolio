Cafeteria App

Overview

The Cafeteria App is a desktop app for ordering food from a campus cafeteria. A student creates an account, logs in, scrolls through the menu (drinks, main meals, swallow, protein and snacks), adds what they want to a cart and places the order. Every order is saved, so they can look back at what they bought and how much it came to.

There is also a manager login that opens a separate dashboard, where the cafeteria staff can add new meals, change prices and keep the stock count right.

The problem I solved

At lunch time the cafeteria queue gets long and a lot of the wait is people asking what’s available and how much it costs. Staff also had no easy way to see what was running low. I wanted one app where students can see the menu, prices and what’s left before they order, and where the stock goes down on its own every time an order is placed.

Features

  • Sign up and log in, with passwords hashed using BCrypt before they go into the database.
  • Menu grouped by category, showing the price and how many are left of each item.
  • Cart where you can change quantities or remove items, with the total updating as you go.
  • Placing an order saves it with all its items and takes the quantities off the stock.
  • Order history page listing past orders with their items and totals.
  • Wallet and profile pages, plus a bottom navigation bar to move between them.
  • Manager dashboard to add, edit and delete menu items and set the stock.

Technologies used

  • Java
  • JavaFX
  • FXML
  • CSS
  • PostgreSQL
  • JDBC
  • BCrypt
  • NetBeans

The screens are built in FXML and styled with a JavaFX stylesheet. Each screen has its own controller, and the data lives in four PostgreSQL tables: users, menu_items, orders and order_items.

What I learned

  • How to connect a Java app to PostgreSQL with JDBC and use prepared statements instead of building SQL strings by hand.
  • Database calls can freeze a JavaFX window, so the login and sign up checks run in a background Task with a loading spinner on top.
  • Splitting the app into FXML views and controllers made it much easier to add new screens later.
  • Next I want to finish the wallet top up and add a search bar to the menu.
